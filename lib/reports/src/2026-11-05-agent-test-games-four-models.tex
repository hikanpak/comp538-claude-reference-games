\lrscope
The question is how four reference models score on the \lrv{Games} ALFWorld test games, the \texttt{valid\_unseen} split.
Elm, Birch, Cypress and Ironwood are anonymized names, and a longer name is a larger model.
Each model played each game once in a fresh process, in a new empty folder with no settings, limited to the player's \texttt{start} and \texttt{step} commands, and the saved games were then replayed in the real game on the Mac.

%%----------------------------------------------------------------------------
\lrresult
Birch, Cypress and Ironwood each won all \lrv{Games} test games and Elm won \lrv{ElmWon} (Empirical), so this list does not separate the first three models.
All \lrv{ElmLost} Elm losses are \texttt{clean cloth} games in room 424, where Elm took a towel, judged the game stuck and stopped after \lrv{ElmStopLow} to \lrv{ElmStopHigh} steps.
The runner counts a process that stops before the game ends as a lost game.
Birch, Cypress and Ironwood took \lrv{StepsLow} to \lrv{StepsHigh} steps on average and Elm took \lrv{ElmSteps}, against \lrv{PlanSteps} for the plan that ships with each game, which uses known object locations.
Replaying every saved game gave \lrv{ReplayFailed} mismatches in any observation, win or step count.
Every tool call in the transcripts is the player's own command, apart from \lrv{OtherCommands} empty placeholders from Elm, and \lrv{NamingFiles} tool results name a game file.
